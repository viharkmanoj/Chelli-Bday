# Chelliamma Birthday Website — GitHub Pages

## Upload
1. Extract this ZIP.
2. Upload its CONTENTS to the root of your GitHub repository. Do not upload the ZIP itself or put everything inside another folder.
3. Keep index.html, style.css, app.js, messages.js, lotus.svg, all three audio files and .nojekyll together.
4. In Settings > Pages, choose Deploy from a branch, main, /(root), then Save.
5. Your site will be https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/.

There is no build or dependency installation. .nojekyll is an empty file that disables Jekyll processing.

## Included behavior
- Blue theme, pink lotuses, all 10 original messages and inline ANNAIYA signatures.
- Opening audio, locked-gift audio, looping background song.
- Automatic music playback is attempted; browsers that block audible autoplay require a tap.
- Confetti on each opening, bold letters, blurred background and Close button.
- Opened boxes stay unwrapped and can be read again; opened status is stored in that browser.

## Moving to a new domain
Opened-box history and completed-review status are browser storage tied to the old website's origin. They do not transfer to GitHub Pages. This does not change the unlock dates or availability.

## Review mode
Append ?review=annaiya3 to your GitHub Pages URL to preview all gifts. Finish review returns to the normal schedule and disables that review in the same browser. Review openings are not permanently saved.
Share the normal URL with Chelliamma, without the review parameter.
This is a static site: date locks are presentation controls, not security. Source files contain the messages and review code. GitHub Pages does not inherit the previous site's private access settings.
